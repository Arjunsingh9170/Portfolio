# Arjun Singh - Professional Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, JavaScript, and Bootstrap.

## 🚀 Features

- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: Smooth scrolling, hover effects, and dynamic content
- **Professional Sections**:
  - Hero section with animated elements
  - About section with personal information
  - Skills section with progress bars
  - Projects showcase
  - Education and certifications
  - Contact form with validation

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Custom styling with animations and responsive design
- **JavaScript**: Interactive features and form handling
- **Bootstrap 5**: Responsive framework and components
- **Font Awesome**: Icons and visual elements
- **Google Fonts**: Typography (Poppins font family)

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Customize** the content in `index.html` to match your information
4. **Update** images in the `public/` directory
5. **Modify** styles in `styles.css` if needed

## 📱 Responsive Breakpoints

- **Mobile**: < 576px
- **Tablet**: 576px - 768px
- **Desktop**: > 768px

## 🔧 Customization

### Updating Personal Information
1. Edit the content in `index.html`
2. Replace images in the `public/` directory
3. Update contact information and social links

1. Edit `styles.css` for custom styling
2. Update CSS variables for color scheme changes
3. Modify animations and transitions

1. Add HTML structure in `index.html`
2. Add corresponding styles in `styles.css`
3. Update navigation menu if needed
